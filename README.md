# 🎓 Student Management Database System

A SQL-based relational database project designed to manage students, teachers, courses, enrollments, attendance, assignments, grades, and fee payments.

This project demonstrates database design, SQL programming, and real-world database management concepts used by educational institutions.

---

## 📌 Project Objective

The goal of this project is to design and implement a normalized relational database that can efficiently manage academic and administrative information for a college or university.

The database supports:

- Student Management
- Teacher Management
- Course Management
- Student Enrollment
- Attendance Tracking
- Assignment Management
- Grade Management
- Fee Payment Management
