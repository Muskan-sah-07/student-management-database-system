# Database Testing

The database was tested to verify that the tables, relationships, constraints, database objects, and queries work as expected.

## Tables

All required tables were created successfully and populated with sample data.

## Primary Keys

Primary key constraints were tested to ensure that each record has a unique identifier.

## Foreign Keys

Foreign key relationships were tested to ensure that related records reference valid parent records.

## Unique Constraints

Unique constraints were tested to prevent duplicate values in fields that require uniqueness.

## Check Constraints

Check constraints were tested to prevent invalid values from being inserted.

## Default Constraints

Default values were tested to ensure that appropriate values are automatically assigned when a value is not provided.

## Indexes

Indexes were created and verified for columns frequently used in queries and relationships.

## Views

Views were executed successfully to verify that they return the expected data.

## Triggers

Triggers were tested to verify that the defined actions occur automatically when the associated database operation is performed.

## Queries

SQL queries were executed to verify:

- JOIN operations
- Subqueries
- Window functions
- Filtering
- Aggregation
- Reporting

## Result

The database objects and SQL queries were tested successfully against the sample dataset.
